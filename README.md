Подъячий Глеб, Керимов Андрей, Мамбетов Родион, Черакаев Антон, Кулиш Артём.

## Как открыть сайт

Дважды щёлкнуть `Открыть_сайт.bat`.

Откроется страница защиты: объяснение, презентация на 15 слайдов и живые примеры алгоритмов. Кнопка «контрольная» это отдельная работа со сроком 29.11.2026, к защите команды она не относится.

Текст, кто что говорит: [Речь_на_защиту.txt](Речь_на_защиту.txt).

## Как повторить замеры

Нужны Python 3, Node.js, JDK 17, компилятор C# и Visual Studio с C++.

```
python run_bench.py
```

Сборка Java, C# и C++ идёт во временной папке с латинским именем: на этой машине javac портит кириллицу в пути. Готовые цифры уже лежат в `results`.
