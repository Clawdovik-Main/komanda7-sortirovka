Команда 7. Сортировка в современных языках программирования.

Что открыть на защите
1. demo.html двойным щелчком. Страница длинная: слева меню, сверху бегущая строка, свой курсор и шлейф.
   Для показа хватает блока «Пульт защиты», ловушки, устойчивости и титров.
2. Презентация_команда7.pptx, 15 слайдов, та же розовая палитра.
3. Речь_на_защиту.txt, у каждого свой фрагмент примерно на минуту.

Порядок выступления
Подъячий Глеб, Керимов Андрей, Мамбетов Родион, Черакаев Антон, Кулиш Артём.
Глеб открывает тему и в конце говорит вывод.

Как повторить замеры
Нужны Python 3, Node.js, JDK 17, компилятор C# из .NET Framework и Visual Studio 2022 с C++.
В этой папке:

    python run_bench.py

Скрипт заново создаёт одинаковые массивы, собирает Java, C# и C++ и пишет results\raw.txt.
Сборка идёт во временной папке с латинским именем, потому что javac на этой системе портит кириллицу в аргументах.

Распределение_обязанностей.docx

Подписи в формах самооценки оставлены пустыми: их ставят на защите.
Вклад в формах разложен поровну, по 20 процентов, по одному языку на человека.
Если кто-то хочет поправить свою строку, это делается до подписи.

Зависимости для повторного замера не ставятся через pip: хватает стандартных библиотек языков.
Графики и презентация уже собраны. Чтобы собрать их заново, нужен пакет python-pptx и matplotlib, скрипт generate_materials.py.
