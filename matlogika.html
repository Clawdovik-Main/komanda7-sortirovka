Тавтологии и следование

Практическая работа 8, вариант 1. Номер в списке 26. Зелёная клетка это 1, розовая это 0. Последний столбец тавтологии зелёный во всех строках. Следование ломается одной строкой: слева 1, справа 0.

Словарь

1Истина. В таблицах пишем 1. Буква И в варианте значит любая истина.
0Ложь. В таблицах пишем 0. Буква Л значит любая ложь.
¬Не. Переворот: ¬1 = 0, ¬0 = 1. Два отрицания возвращают букву.
∧И. Единица только когда обе части равны 1. Знак & на листе значит то же.
∨Или. Ноль только при 0 ∨ 0. Хватает одной единицы.
→Если, то. Ложь только при 1 → 0. Знак ⊃ на листе это та же стрелка.
↔Эквивалентность. Единица, когда части равны. Знак ~ значит то же.
≡Равносильность. Столбцы совпали во всех строках. Это тавтология A ↔ B.
⊨Следование. Нет строки, где слева 1, а справа 0. Обратно может не быть.

2. Есть ли логическое следование

На листе все одиннадцать пунктов названы следованиями. У 2а, 2в и 2ж есть запрещённая строка. У остальных её нет.

2а)Следования нет

(P ∨ ¬R) → Q ⊨ (P → Q) ∧ R

Контрпример P = 0, Q = 1, R = 0. Слева (0 ∨ 1) → 1 = 1. Справа (0 → 1) ∧ 0 = 0.

P = 0, Q = 1, R = 0слева 1справа 0
2б)Следование есть

(P → Q) → R ⊨ P → (Q → R)

Правая часть равна 0 только при P = 1, Q = 1, R = 0. Тогда слева (1 → 1) → 0 = 0.

2в)Следования нет

(P ∨ Q) → R ⊨ (P ∧ ¬Q) ∨ R

Контрпример: все три буквы равны 0. Слева 0 → 0 = 1. Справа 0.

P = Q = R = 0слева 1справа 0
2г)Следование есть

(P → Q) → R ⊨ (P ∧ Q) → R

Правая часть равна 0 только при P = Q = 1 и R = 0. Тогда слева (1 → 1) → 0 = 0.

2д)Следование есть

(P ∧ Q) → R ⊨ P → (Q → R)

Это даже равносильность. Обе части равны 0 ровно при P = Q = 1 и R = 0.

2е)Следование есть

(P ↔ Q) ∨ R ⊨ (¬P → ¬Q) ∨ R

Если R = 1, справа уже 1. Если R = 0, слева остаётся P ↔ Q, а из него получается ¬P → ¬Q.

2ж)Следования нет

(P ∨ R) ↔ Q ⊨ (P ∨ R) ↔ R

Контрпример P = 1, Q = 1, R = 0. Слева (1 ∨ 0) ↔ 1 = 1. Справа (1 ∨ 0) ↔ 0 = 0.

P = 1, Q = 1, R = 0слева 1справа 0
2з)Следование есть

¬(P ∨ Q) ⊨ ¬P ∨ R

Равносильности нет: справа лишняя буква R. Если слева 1, то P = 0, значит ¬P = 1, значит ¬P ∨ R = 1.

2и)Следование есть

(P ∨ Q) → R ⊨ (P → Q) ∨ (P ↔ R)

Правая часть равна 0 только при P = 1, Q = 0, R = 0. Тогда слева (1 ∨ 0) → 0 = 0.

2к)Следование есть

P ∧ (Q ∨ R) ⊨ (P ∨ Q) ∧ (P ∨ R)

Если слева 1, то P = 1. Обе скобки справа содержат P и тоже равны 1.

2л)Следование есть

(P ∧ Q) ∨ R ⊨ P ∨ (Q → R)

Если сработало R, то Q → R = 1. Если сработало P ∧ Q, то справа уже есть P = 1.
