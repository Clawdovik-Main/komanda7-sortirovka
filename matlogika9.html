Предикаты и кванторы

Практическая работа 9, вариант 1. Номер в списке 26. Предикат по слайду это функция в истину или ложь. Квантор уменьшает число свободных переменных. Из одноместного предиката получается высказывание.

Словарь

Предикат

k-местный предикат на множестве M ставит каждому набору из k элементов истину или ложь. «x делится на 5» это предикат. «x² + 2x + 4» это число, предиката нет.

∀, квантор общности

«Для каждого x». ∀x A(x) истинно, только если A верно при всяком значении x из области.

∃, квантор существования

«Найдётся x». ∃x A(x) истинно, если есть хотя бы одно значение, при котором A верно.

Терм

Имя объекта. Переменная, константа и функция от термов. 3 + 4 это терм, не высказывание.

Формула

Атомарная формула P(t1, ..., tk). Отрицание формулы. Две формулы в скобках под ∧, ∨, →, ↔. Квантор перед формулой.

Свободная и связанная

Квантор связывает переменную только в своей области действия. Вхождение вне этой области свободно.

Порядок кванторов

Нажми число x. Для суммы 7 подходящее y всегда находится: это 7 − x. Одно и то же y на все x сразу не находится.

∀x ∃y (x + y = 7): истина ∃y ∀x (x + y = 7): ложь

1. Какие выражения являются предикатами

1а)Предикат

«x делится на 5», x из натуральных

Одно место. При x = 10 получается истина, при x = 3 ложь.

1б)Предикат

«Река x впадает в Байкал»

Одно место, область это названия рек. Селенга даёт истину, Волга ложь.

1в)Не предикат

x² + 2x + 4

Это терм, число. Истины или лжи здесь нет.

1г)Предикат

(x + y)² = x² + 2xy + y²

Два места. Равенство даёт истину или ложь. Здесь истина при всех действительных, но это всё ещё предикат, пока x и y не связаны квантором.

1д)Предикат

«x есть брат y»

Два места, область это люди.

1е)Предикат

«x и y по разные стороны от z»

Три места: две точки и прямая.

1ж)Не предикат

ctg 45° = 1

Свободной переменной нет. Это готовое высказывание, и оно истинно.

1з)Предикат

«x перпендикулярна y»

Два места, область это прямые одной плоскости.

1и)Предикат

x² + x − 6 = 0

Одно место. Истина при x = 2 и x = −3, ложь при остальных действительных.

1к)Не предикат

«Для всех x верно x² + x − 6 = 0»

Квантор уже связал x. Получилось высказывание, и оно ложно: не каждое число является корнем.

2. Истина или ложь на действительных числах

2а)Истина

∀x ∃y (x + y = 7)

Для выбранного x берём y = 7 − x. Такое число есть всегда.

2б)Ложь

∃y ∀x (x + y = 7)

Одно y должно годиться для всех x. Для x = 0 нужно y = 7, для x = 1 нужно y = 6. Одного y нет.

2в)Ложь

∃x ∀y (x + y = 7)

Та же причина, только общее число теперь называется x.

2г)Ложь

∀x ∀y (x + y = 7)

0 + 0 = 0, это не 7.

2д)Истина

[∀x ∀y (x + y = 3)] → (3 = 4)

Слева ложь, справа ложь. Импликация из лжи истинна.

2е)Истина

∀x [x² > x ↔ (x > 1 ∨ x < 0)]

x² − x > 0 это x(x − 1) > 0, то есть x < 0 или x > 1. Части совпадают при каждом x.

2ж)Истина

∀a [(∃x ax = 6) ↔ (a ≠ 0)]

При a ≠ 0 берём x = 6/a. При a = 0 уравнение 0 = 6 решений не имеет.

2з)Ложь

∀b ∃a ∀x (x² + ax + b > 0)

Минимум параболы равен b − a²/4. Он больше нуля, только если b > 0. При b = 0 или b < 0 такого a нет, а квантор требует все b.

2и)Истина

∀x [(x > 1 ∨ x < 2) ↔ (x = x)]

Любое действительное число либо больше 1, либо меньше 2. Справа тоже всегда истина.

2к)Истина

∃b ∀a ∃x (x² + ax + b = 0)

Возьмём b = 0. Тогда x(x + a) = 0, корень x = 0 есть при любом a.

2л)Ложь

∃a ∀b ∃x (x² + ax + b = 0)

Какое бы a ни взять, при b = a²/4 + 1 дискриминант равен −4. Действительного корня нет.

3. Какие выражения являются формулами

По слайду связка соединяет ровно две формулы и стоит в скобках. Внешние скобки целой формулы можно не писать, как в работе 7. Три части под одной связкой без попарных скобок формулой не являются.

3а)Формула

(∃x)(B(x)) → (∀x)(B(x))

Обе части формулы. Стрелка соединяет их, внешние скобки опущены.

3б)Формула

(∀x)(P(x)) → P(y)

Слева формула, справа атомарная формула. y свободна.

3в)Не формула

(∀x)((P(x) ∧ Q(x)R(x)) → (∃y)(¬S(x)))

Q(x)R(x) это две формулы, написанные подряд, без связки.

3г)Формула

(∀x)(Q(x) ∧ ¬R(x))

Внутри скобок ровно две формулы под ∧.

3д)Не формула

(∃x)(P(x) ∧ Q(x) ∧ ¬R(x))

Под одной парой скобок три части. Нужно ((P(x) ∧ Q(x)) ∧ ¬R(x)).

3е)Формула

(∃x)(E(x) ∧ D(x, y))

Две формулы в скобках. y свободна, x связана.

3ж)Не формула

(∀x)(P(x) ∨ Q(x)) → (∃x)(P(x) → Q(x) ∨ R(x))

Справа внутри скобок сразу две связки, → и ∨, без попарных скобок.

3з)Формула

¬P(x) ∧ (∀y)(P(y))

Отрицание формулы и кванторная формула. Внешние скобки конъюнкции опущены. x свободна, y связана.

3и)Не формула

(∃x)(∃y)(x ≠ y ∧ P(x) ∧ P(y))

Снова три части под одним ∧. Нужны вложенные скобки.

3к)Формула

¬[(∃x)(P(x)) → (∀x)(P(x))]

В скобках импликация двух формул, снаружи отрицание.

3л)Формула

(∀x)[E(x) → (∀y)(D(x, y) → E(y))]

Скобки каждый раз соединяют две готовые формулы.

3м)Формула

(∃y)[P(y) ∧ (∀x)(Q(x, y) ∨ R(x))]

Внутри ∨ стоит в своих скобках, снаружи ∧ соединяет две формулы.

А)Два предиката

3 + 4 = 7

Предикат P(x, y): «x + y = 7». Область это числа. Подставляем x = 3 и y = 4.

Вера и Надежда сёстры

Предикат S(x, y): «x и y сёстры». Область это люди. Подставляем x = Вера и y = Надежда.

Б)Свободные и связанные

(∀x)(P(x))

Оба вхождения x связанные: одно в кванторе, другое в P(x). Свободных переменных нет, это высказывание.

(∀x)(P(x)) → P(y)

Область квантора только (P(x)). Оба x связанные. y в P(y) свободна, квантор её не трогает.

x связана y свободна
