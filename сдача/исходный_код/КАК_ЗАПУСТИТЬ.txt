Исходники пяти языков лежат в папке src рядом с этим файлом.
Те же файлы, которыми меряет проект, лежат в src в корне Команда7.

Сайт: в корне Команда7 дважды щёлкнуть Открыть_сайт.bat.
Замеры: в корне Команда7 выполнить python run_bench.py.

Нужны Python 3, Node.js, JDK 17, компилятор C# и Visual Studio 2022 с C++.
Сборка Java идёт во временной папке с латинским именем.
